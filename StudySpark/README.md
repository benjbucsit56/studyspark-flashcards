# StudySpark — Flashcard Study App

A beginner-friendly static web application starter for the CPP123 Emerging Technology individual final project.

## Included files
- `index.html` — dashboard, subject decks, study session, and flashcard collection
- `styles.css` — purple/lavender responsive styling
- `app.js` — create/edit/delete flashcards and decks, flip-card study mode, progress tracking, search, filtering, and shuffle
- `privacy.html` — privacy policy
- `README.md` — instructions

## Run locally
1. Extract the ZIP archive.
2. Open `index.html` in a modern browser.
3. Try creating a subject deck and adding a flashcard.
4. Click the study card to reveal the answer.
5. Mark a card remembered or needing practice.
6. Search by a word from the question, answer, or subject.
7. Refresh the page to confirm that data persists in that browser.

The app uses HTML, CSS, JavaScript, and browser local storage. No build step, package manager, account system, or database is required.

## Data and privacy
- Data is stored in local storage in the current browser profile.
- Do not enter sensitive personal information.
- The stylesheet uses Google Fonts; hosting providers may also keep technical access logs.
- Review and update the contact text in `privacy.html` before deployment. Make sure the final policy accurately describes the final implementation and host.

## Publish using GitHub Pages
1. Sign in to GitHub or create an account.
2. Create a public repository, e.g. `studyspark-flashcards`.
3. Upload `index.html`, `styles.css`, `app.js`, `privacy.html`, and `README.md` to the repository root.
4. Open **Settings → Pages**.
5. Choose **Deploy from a branch**, then select `main` and `/ (root)` and save.
6. Wait for GitHub Pages to publish and copy the URL it provides.
7. Open the public URL and test the app and the Privacy Policy in a different browser or private window.

The GitHub interface can change; follow its current Pages instructions if the labels differ.
